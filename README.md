# Employee Management System

## 📌 Project Overview

The Employee Management System is a web-based application developed to simplify and manage employee information. It provides a centralized platform for managing employee records and departmental details through a simple interface.

This project was developed as part of my Bachelor of Computer Applications (BCA) academic work.

## 🚀 Features

- User Login System
- Employee Dashboard
- Add New Employees
- View Employee Details
- Edit and Update Employee Information
- Delete Employee Records
- Department Management
- MySQL Database Integration

## ⚙️ Installation and Setup

Follow these steps to run the project locally:

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Move the project folder into the `htdocs` directory inside XAMPP.
4. Open XAMPP Control Panel and start Apache and MySQL.
5. Open `http://localhost/phpmyadmin/`.
6. Create a MySQL database using the database name configured in the PHP files.
7. Import the provided `.sql` database file.
8. Configure the database connection settings in the relevant PHP file.
9. Open your browser and visit:

```text
http://localhost/Employee-Management-System/
```
